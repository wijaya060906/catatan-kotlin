#📝 Catatan-Kotlin 📝

Aplikasi **Catatan-Kotlin** adalah aplikasi catatan sederhana namun kaya fitur yang dirancang untuk membantu pengguna mengelola catatan pribadi dengan mudah dan efisien. Dibuat menggunakan **Kotlin**, aplikasi ini juga memanfaatkan **Firebase Authentication** untuk keamanan pengguna serta **Room Database** untuk menyimpan data catatan secara lokal.

## Fitur Utama

1. **Membuat Catatan**
   - Pengguna dapat membuat catatan baru dengan mudah. Setiap catatan dapat diberi genre sesuai dengan preferensi pengguna, seperti Pribadi, Kerja, atau Hiburan.

2. **Berbagi Catatan**
   - Catatan yang telah dibuat dapat dibagikan dengan pengguna lain, mirip seperti fitur berbagi di media sosial. Hal ini memungkinkan pengguna untuk saling berbagi ide, inspirasi, atau informasi penting.

3. **Autentikasi Aman**
   - Menggunakan **Firebase Authentication**, pengguna dapat membuat akun dan login dengan aman untuk melindungi catatan mereka.

4. **Penyimpanan Lokal**
   - Semua catatan disimpan secara lokal menggunakan **Room Database**, memastikan akses cepat dan efisiensi data.

5. **Tampilan Simpel dan Nyaman**
   - Aplikasi dirancang dengan antarmuka pengguna yang minimalis dan intuitif, memberikan pengalaman pengguna yang nyaman.

## Teknologi yang Digunakan
- **Bahasa Pemrograman**: Kotlin
- **Backend**: Firebase Authentication
- **Database Lokal**: Room Database
- **Fitur Tambahan**: Fitur berbagi mirip media sosial
